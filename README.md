A dislocation-only cbBTC trading bot: it waits for a real washout (15-minute return at or below -0.8% with two confirming up closes), buys once at full size, sells the rebound at +2% (or on a tight stop / trailing pullback), and makes at most 2 round trips in 24 hours.

## Run it

```sh
node main.ts
```
